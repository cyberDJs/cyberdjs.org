Support

CyberSKILLS is a read-only capability directory and MCP integration operated by CyberDJs. This page covers the public ChatGPT-facing service at https://cyberskills.cyberdjs.org/mcp.

Need help?

Email booking@cyberdjs.org with the subject CyberSKILLS support. This is the current public CyberDJs contact address while a dedicated support alias is being introduced.

What to include

  • what you were trying to do;
  • the CyberSKILLS tool involved;
  • expected and actual behavior;
  • reproduction steps;
  • the approximate time of the issue and, if visible, the runtime or registry revision.

Current public tools

  • cyberskills_runtime_status — inspect runtime and registry identity;
  • cyberskills_get_capability — inspect one capability by exact ID;
  • cyberskills_search_capabilities — search the read-only capability registry.

Security reports

Do not send passwords, API keys, access tokens, private keys, or unrelated personal data. If you believe you found a security vulnerability, mark the email subject CyberSKILLS security and provide only the minimum information needed to reproduce the issue safely.

Availability

CyberSKILLS is currently Alpha. No uptime or response-time SLA is promised. The service may be changed, interrupted, or temporarily unavailable while the capability model and runtime adapters evolve.

Scope: the public ChatGPT integration is intentionally read-only. It does not install, publish, delete, modify, or execute capabilities on a user's behalf.
