CyberSKILLS / privacy

Privacy Policy

This policy explains how CyberDJs handles information when you use the public CyberSKILLS website and read-only ChatGPT MCP integration.

What CyberSKILLS does

CyberSKILLS lets a user or ChatGPT search and inspect a centrally managed registry of AI capabilities. The public MCP surface is read-only and currently exposes runtime status, exact capability lookup, and bounded capability search.

Information processed

The service processes only the inputs required for a requested tool call:

  • no arguments for runtime status;
  • a capability identifier for exact lookup;
  • a search query and bounded result limit for capability search.

The service also necessarily receives ordinary network and request metadata used to operate an HTTPS service, such as timestamps, request paths, IP/network information, response status, and diagnostic errors.

Purpose

Inputs are processed to return requested capability metadata, maintain service reliability, diagnose faults, protect the service against abuse, and verify compatibility and deployment health.

Storage and retention

CyberSKILLS does not intentionally create user profiles or store MCP tool arguments as application records. Operational infrastructure may generate request and error logs. Such logs are intended to be retained only for operational, security, and troubleshooting needs and should be minimized where practical.

Recipients and service providers

Information may be processed by the infrastructure providers required to run the service and by OpenAI/ChatGPT when you invoke CyberSKILLS through ChatGPT. CyberDJs does not sell CyberSKILLS user data.

Data returned by the service

Responses contain capability-registry metadata and runtime/registry status. The public interface is designed not to return authentication secrets, private credentials, unrelated personal data, or hidden internal service URLs.

Cookies and tracking

The CyberDJs pages used for CyberSKILLS support, privacy, and terms do not intentionally set application cookies or load advertising or behavioral-tracking scripts. Infrastructure providers may still process ordinary request metadata required to deliver the pages.

Your choices and requests

You may contact CyberDJs to ask about information associated with your use of CyberSKILLS, to raise a privacy concern, or to request correction or deletion where applicable and technically identifiable. Because the service does not intentionally maintain user profiles, CyberDJs may not always have application data that can be linked back to a specific person.

Privacy contact

Email booking@cyberdjs.org with the subject CyberSKILLS privacy. This is the current public CyberDJs contact address while a dedicated privacy/support alias is being introduced.

Security and minimization

The public tool surface is read-only, uses bounded inputs and HTTPS transport, and is designed to request and return only data necessary for capability discovery. Compatibility that has not been verified remains unknown.

Changes to this policy

This policy may be updated as CyberSKILLS moves beyond Alpha, adds new capabilities, or changes infrastructure. The current version and date will remain published at this URL.
